Use RipClip to plan the week: $ARGUMENTS

Use the platforms named (TikTok, YouTube Shorts and Instagram Reels if none) and the user's IANA time zone (ask if it is unknown). `plan_posts` with 3 clips, then show each draft with its time and `review_url`, and `show_drafts` for the calendar. The user schedules them in RipClip; nothing is posted.
